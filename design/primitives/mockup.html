0 · Theming model

Three token tiers palette → semantic → component

/* 1. palette — raw ramps, swap to rebrand everything */ --onyx-palette-blue-600: #205EA6; /* 2. semantic — the public theme API every component reads */ --onyx-control-button-bg: var(--onyx-palette-blue-600); --onyx-tone-danger-fg: var(--onyx-palette-red-400); /* 3. component — defaults to semantic; override one component alone */ --onyx-button-radius: var(--onyx-radius-md); --onyx-menu-item-height: var(--onyx-control-height-md); /* Styling hooks on every part */ <button data-slot="button" data-variant="secondary" data-size="sm" data-state="loading"> /* All Onyx CSS lives in @layer onyx.base, onyx.components → app CSS wins, no !important */

Every primitive: tokens only (no raw hex/px), data-slot on each part, data-state/data-variant/data-size/data-tone hooks, className merge, asChild, exported variant functions, and a headless hook where behaviour is non-trivial (useListbox, useTree, useResizable, useFloating…).
