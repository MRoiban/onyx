# Code

**Use when:** showing an inline identifier, path or code fragment. **Not for:** multiline code blocks or editable source.

Anatomy: `data-slot="code"`. `Code` forwards its ref and accepts native code element props, `className`, and `asChild`; exports `codeVariants`.

Tokens: `--onyx-font-mono`, `--onyx-code-padding-x`, `--onyx-code-padding-y`, `--onyx-radius-xs`, `--onyx-control-secondary-bg`, `--onyx-border-subtle`. No behavioral hook.
