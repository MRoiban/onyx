## Public API per primitive

- **Popover:** Popover, Trigger, Anchor, Content, Arrow, Close, Portal, Header, Body, Footer; `popoverVariants`. Radix controlled/uncontrolled open state, modal option, focus management, collision-aware anchor positioning. Content adds `container` and defaults to an 8px gap/padding.
- **Menu:** Menu, Trigger, Content, Item, CheckboxItem, RadioGroup, RadioItem, Label, Separator, Shortcut, Group, Portal, Sub, SubTrigger, SubContent. Item/SubTrigger support `tone="neutral|danger"` and `inset`. Shared `menu{Content,Item,Label,Separator,Shortcut}Variants` are exported. Radix owns arrows, typeahead, checkbox/radio selection and submenu focus. Items with adornments preserve a single asChild element.
- **Tooltip:** TooltipProvider, TooltipRoot, Tooltip, Trigger, Content, Arrow, Portal; `tooltipVariants`. Convenience `<Tooltip content={...} shortcut={...}>` uses a single child trigger; composable parts retain all Radix props. Provider supplies grouped delays. Shortcut renders Kbd; Content supports `container`.
- **Truncate:** Truncate, `truncateVariants`, `useTruncate`. String children or `text`, end/middle modes, trailing-character count, overflow-only tooltip, ref/className/asChild. Hook returns element and full-text measurement refs plus overflowing state; ResizeObserver and font readiness update measurement.
- **HoverCard:** HoverCard, Trigger, Content, Arrow, Portal, Header, Body, Footer; `hoverCardVariants`. Radix hover/focus delays and dismissal; collision-aware content with `container`.
- **AlertDialog:** AlertDialog, Trigger, Content, Overlay, Portal, Icon, Header, Body, Footer, Title, Description, Action, Cancel; `alertDialogVariants`. Content tone is inherited by Icon; Cancel initially receives focus; Action has destructive styling; outside interaction cannot dismiss; Escape cancels.
- **Sheet:** Sheet, Trigger, Content, Overlay, Portal, Close, Header, Body, Footer, Handle, Title, Description; `sheetVariants`. Dialog behavior; left/right/top/bottom placement; bottom inserts a handle; Content accepts `container`.
- **Menubar:** Menubar, MenubarMenu, Trigger, Content, Item, CheckboxItem, RadioGroup/Item, Group, Label, Separator, Shortcut, Portal, Sub/SubTrigger/SubContent; `menubarVariants` and shared menu variants. Radix horizontal categories and full command-menu keyboard behavior.
- **NavigationMenu:** NavigationMenu, List, Item, Trigger, Content, Link, Indicator, Viewport; `navigationMenuVariants`. Radix navigation semantics and focus; Floating UI anchors portalled link-card content to the navigation root, matches width, and applies viewport flip/shift/size constraints with 8px padding. Consumers may override content width/styles.
- **Combobox:** Combobox, ComboboxHighlight, `comboboxVariants`, `useCombobox`, ComboboxOption/Value/Props and UseComboboxOptions. Controlled/uncontrolled single/multiple values, query, open and active index; consumer filtering or substring filtering; highlights; enabled-option navigation; aria-activedescendant; create slot/callback; empty state; optional Tag chips and rendering overrides. Ref points to the input. Hook exports state, setters, input/listbox/option bindings, selection and removal.
- **DatePicker:** DatePicker, `datePickerVariants`, `useDatePicker`, DatePickerProps/UseDatePickerOptions. Built last against W2's actual Calendar; single ISO editing, invalid input preservation, range selection, locale/bounds/disabled options, form values, controlled/uncontrolled open/value and styling props. Calendar owns date math and keyboard grid behavior. Popup initially focuses its tabbable day and closes after a completed selection.

All DOM parts have slots, forwarded refs, merged classes and relevant states. Structural and Radix single-element parts accept asChild; composite input widgets use their headless hooks/rendering props for alternate markup. No raw palette/hex colors are read by W1 component styles. Body portals follow the document theme/density per W0's contract.

Documented deviations:

- Real body portals can extend beyond a cell instead of being clipped by the mockup's overflow. This preserves usable content and actual collision behavior; the navigation panel may extend slightly below the comfortable cell.
- Comfortable Menu stage grows from 350px to 392px so its real menu does not cover the explanatory note. The static reference's fixed height does not accommodate the larger menu rows.
- Modal demos use separate documents to keep two real modal focus traps from disabling the gallery. Their capture-only max-height allows both safe/destructive actions to remain visible inside the 220px stage; normal library behavior retains viewport scrolling. Text wrapping and the header icon row vary with real font metrics.
- The Tooltip uses semantic `control-button-fg`/`border-strong`, rather than the reference's raw base-200/base-800 palette reads. This obeys the token contract; foreground is slightly brighter. Kbd uses inherited foreground and a transparent fill.
- Radix's real arrow is triangular and anchored to the trigger; the reference draws a diamond corner at a fixed offset. Menubar and navigation can overlap slightly in comfortable mode when both are forced open for the reference state.
- The open-state toggle adds a few pixels to the section heading. Forced static states intentionally prevent the gallery from being dismissed by unrelated demo interaction; disable the toggle to exercise normal behavior.
